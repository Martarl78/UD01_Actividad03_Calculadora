# Calculadora en Kotlin

Calculadora básica por consola con menú interactivo, hecha en Kotlin.

## Operaciones

1. Sumar
2. Restar
3. Multiplicar
4. Dividir
5. Calcular resto
6. Salir

## Cómo ejecutarla

1. Abre el proyecto en IntelliJ IDEA.
2. Ejecuta la función `main` del archivo `src/Main.kt`.
3. Elige una opción del menú e introduce los dos números.

## Detalles

- Acepta números decimales (con `.` o `,`).
- Controla la división entre cero.
- Si se introduce un valor no válido, vuelve a pedirlo.
